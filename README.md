# FastTab React

FastTab 是一个本地优先的 Chrome 新标签页扩展，使用 React 18、TypeScript、Vite 和 Zustand 构建。

## 特性

- 本地书签支持模糊、拼音和使用频率排序，并支持自定义网页搜索引擎
- 快速添加、编辑、删除和拖拽排序书签
- 支持根目录书签、嵌套文件夹、面包屑浏览和一键打开文件夹
- 支持批量移动/删除、重复书签与空文件夹整理，并可撤销最近一次删除或移动
- 可控制文件夹内书签是否同时显示在首页
- 可创建独立首页工作区，对书签和文件夹进行场景化分组
- 监听 Chrome 书签变化，页面自动同步
- 亮色、暗色、跟随系统主题，以及受大小限制的本地/远程背景图片
- 可调整图标尺寸、网格密度、标题行数、最大列数和文件夹顺序
- 键盘导航、清晰焦点态和响应式布局
- favicon 使用 Chrome 本地接口读取，不请求第三方图标服务

## 技术栈

- **React 18+** - 最新的 React 版本
- **TypeScript** - 类型安全的 JavaScript
- **Vite** - 快速的构建工具
- **CSS3** - 现代化的样式，包含动画和渐变
- **Chrome Extension API** - 浏览器扩展功能

## 项目结构

```
FastTabReact/
├── src/
│   ├── components/         # 页面与交互组件
│   ├── hooks/              # favicon、拖拽等 Hooks
│   ├── store/              # 书签、搜索、外观与 UI 状态
│   ├── styles/             # 功能样式
│   ├── types/              # TypeScript 类型
│   ├── utils/              # 书签树、URL、背景存储工具及测试
│   ├── App.tsx             # 新标签页应用
│   ├── newtab.tsx          # 新标签页入口
│   └── popup.tsx           # 扩展弹窗入口
├── manifest.json            # Chrome 扩展配置
├── package.json             # 项目依赖
├── vite.config.ts          # Vite 配置
├── start.sh                # Linux/macOS 启动脚本
└── start.bat               # Windows 启动脚本
```

## 🚀 Chrome 扩展安装和使用指南

### 方法一：开发模式安装（推荐开发者）

#### 1. 构建项目

```bash
pnpm build
```

#### 2. 加载扩展

1. 打开 Chrome 浏览器
2. 在地址栏输入 `chrome://extensions/` 并回车
3. 在右上角开启"开发者模式"开关
4. 点击"加载已解压的扩展程序"按钮
5. 选择 `FastTabReact/dist` 目录
6. 扩展加载成功后，你会看到 "FastTab React" 出现在扩展列表中

#### 3. 使用扩展

- **新标签页**：加载扩展后，打开新标签页会自动显示 FastTab
- **扩展弹窗**：点击工具栏图标可打开新标签页、同步书签或查看快捷键
- **书签管理**：可添加、编辑、删除、拖拽排序和批量整理
- **搜索功能**：输入时优先模糊匹配本地书签，也可使用拼音、切换或添加搜索引擎
- **快捷命令**：搜索框输入 `>` 可添加书签、管理工作区、调整外观或切换主题
- **工作区**：在首页顶部创建和切换不同书签分组，不改变 Chrome 原始目录
- **页面布局**：在背景设置中调整图标尺寸、密度、标题和排列顺序

### 方法二：打包安装（推荐普通用户）

#### 1. 构建项目

```bash
pnpm build
```

#### 2. 打包扩展

1. 在扩展管理页面（`chrome://extensions/`）
2. 找到已加载的 "FastTab React" 扩展
3. 点击"打包扩展程序"按钮
4. 选择 `FastTabReact/dist` 目录作为根目录
5. 点击"打包扩展程序"
6. 会生成 `.crx` 文件和 `.pem` 密钥文件

#### 3. 安装打包后的扩展

1. 将生成的 `.crx` 文件拖拽到 Chrome 扩展管理页面
2. 确认安装
3. 按照上述步骤配置新标签页

### 方法三：从 Chrome Web Store 安装（如果已发布）

1. 访问 Chrome Web Store
2. 搜索 "FastTab React"
3. 点击"添加至 Chrome"
4. 确认安装
5. 配置新标签页

## 🔧 扩展功能说明

### 新标签页功能

- **搜索栏**：模糊/拼音书签联想、自定义搜索引擎和当前/新标签页打开策略
- **书签展示**：根目录书签、置顶书签和文件夹统一展示
- **工作区分组**：按开发、学习或个人等场景组合首页内容
- **文件夹浏览**：单层弹窗、面包屑返回，以及批量在后台打开
- **快速添加**：可选择目标文件夹，并决定是否显示在首页
- **拖拽排序**：通过独立拖拽手柄调整同一文件夹中的顺序
- **管理面板**：支持搜索、筛选、批量移动、显示/收起、删除和数据整理
- **安全撤销**：删除或移动后可在 8 秒内恢复原位置和工作区引用
- **实时同步**：监听浏览器书签的新建、修改、移动和删除事件

### 弹出窗口功能

- **快速操作**：打开新标签页、主动同步书签
- **使用帮助**：内联显示快捷键，不使用系统弹窗
- **状态反馈**：明确显示同步成功或失败原因

### 快捷键

- `⌘/Ctrl + K`：聚焦搜索框
- `⌘/Ctrl + F`：聚焦搜索框
- `↑` / `↓`：选择匹配的书签
- `Enter`：打开所选书签或执行网页搜索
- `Esc`：收起搜索建议或关闭当前弹层

## 🐛 常见问题解决

### 扩展无法加载

- 确保 Chrome 版本在 88 以上
- 检查 `manifest.json` 文件是否完整
- 确认构建成功，`dist` 目录存在

### 新标签页不显示

- 检查扩展权限设置
- 确认新标签页配置正确
- 尝试重启浏览器

### 书签功能异常

- 确认已授予书签权限
- 检查 Chrome 书签 API 是否可用
- 查看浏览器控制台错误信息

### 样式显示异常

- 清除浏览器缓存
- 重新加载扩展
- 检查 CSS 文件是否正确加载

## 🔒 权限说明

扩展需要以下权限：

- **bookmarks**：读取、创建、编辑、移动和删除书签
- **storage**：保存首页展示、主题和搜索引擎偏好
- **favicon**：通过 Chrome 本地 favicon 接口展示站点图标
- **可选站点权限**：仅当用户主动填写远程背景图片 URL 时，按该图片来源申请

书签网址和使用偏好默认只保留在本机。FastTab 不会把 favicon 地址发送给 Google、DuckDuckGo 等第三方图标服务；远程背景仅在用户主动保存指定 URL 时下载一次并本地保存。

## 📱 移动端支持

虽然这是一个 Chrome 扩展，但组件设计支持响应式布局，可以在不同尺寸的屏幕上正常显示。
